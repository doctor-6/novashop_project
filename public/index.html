Frequently asked questions

Quick answers about this university demo project.

Is this a real shop?

No. NovaTech is a fictional storefront built as a university project. There is no real checkout, payment or order fulfilment — everything you see runs locally on your machine.

Where do the products come from?

All products are stored in a small JSON database on the server and served through a REST API. The admin panel edits exactly the same data, so changes appear here after a refresh.

Can I add or edit products myself?

Yes — open the admin panel, log in with the demo password shown there, and manage products, prices and photos. The storefront updates on the next page load.

Are my details safe here?

This demo never asks for payment details and stores no customer accounts. Uploaded photos and product data stay in local folders on the machine running the server.
